# 🎉 大人証明デモ - すぐに起動する方法

## ⚡ 最速 3ステップ起動（今すぐ！）

### 1️⃣ ターミナルを開く

```bash
cd ethglobal2026mumbai/demo
```

### 2️⃣ Streamlit をインストール（初回のみ）

```bash
pip install streamlit
```

**初回は 1-2 分かかります**

### 3️⃣ アプリを起動

```bash
streamlit run app.py
```

## ✅ これで完了！

✨ **ブラウザが自動で開きます** → `http://localhost:8501`

## ⚙️ トラブルシューティング

### 問題: コマンドが見つからない

```bash
# Python のバージョンを確認
python --version

# または
python3 --version
```

Python がインストールされていない場合は [python.org](https://www.python.org/) からダウンロード

### 問題: Streamlit がインストールできない

```bash
# 別の方法でインストール
python -m pip install streamlit --user
```

### 問題: ポート 8501 が既に使用されている

```bash
# 別のポートで起動
streamlit run app.py --server.port 8502
```

別のポートで起動した場合、URL が `http://localhost:8502` に変わります

### 問題: ブラウザが開かない

ターミナルに表示される以下の URL をコピーしてブラウザに貼り付け：

```
Local URL: http://localhost:8501
Network URL: http://192.168.x.x:8501
```
