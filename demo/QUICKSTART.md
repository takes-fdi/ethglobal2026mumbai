# 🚀 大人証明デモ - 5分で起動

## 📋 前提条件

- Python 3.8 以上がインストールされていること
- インターネット接続

## ⚡ 30秒クイックスタート

### ステップ1: デモディレクトリに移動

```bash
cd ethglobal2026mumbai/demo
```

### ステップ2: Streamlit をインストール（初回のみ）

```bash
pip install streamlit
```

### ステップ3: アプリを起動

```bash
streamlit run app.py
```

### ✅ 完了！

ブラウザが自動で開き、デモアプリが起動します（30秒待機）

```
Local URL: http://localhost:8501
```

## 🐛 よくある質問

### Q1: ブラウザが開かない

ターミナルに表示される URL をコピーして、手動でブラウザに貼り付け：

```
Local URL: http://localhost:8501
```

### Q2: ポート 8501 が既に使用されている

別のポートで起動：

```bash
streamlit run app.py --server.port 8502
```

### Q3: アプリが遅い

キャッシュをクリア：

```bash
streamlit cache clear
```

### Q4: Streamlit がインストールできない

別の方法でインストール：

```bash
python3 -m pip install --user streamlit
```

### Q5: Python がインストールされていない

[python.org](https://www.python.org/downloads/) から最新版をダウンロード

## 🔧 アプリをカスタマイズする

### 手数料を変更

`app.py` 内の以下を検索：

```python
st.markdown("**手数料:** 0.001 ETH (約10円)")
```

を変更：

```python
st.markdown("**手数料:** 0.0005 ETH (約5円)")
```

### ロゴを追加

`app.py` の `splash_screen()` 関数内に追加：

```python
st.image("logo.png", width=200)
```

### SaaS企業を追加

`app.py` の `main_screen()` 関数内の `# テスト機能` セクション後に追加：

```python
if st.button("Disney+ からリクエスト", use_container_width=True, key="req_disney"):
    st.session_state.current_saas = "Disney+"
    st.session_state.page = "verification_request"
    st.rerun()
```
