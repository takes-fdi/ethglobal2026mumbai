## UIコンポーネント仕様

### ボタン

**プライマリボタン（アクション実行）**
```
┌──────────────────────────┐
│  ✓ 確認する / 進む         │  背景: #007AFF (青)
└──────────────────────────┘  文字: 白, サイズ: 16px
```

**セカンダリボタン（キャンセル）**
```
┌──────────────────────────┐
│  キャンセル / 戻る       │  背景: #f0f0f0 (グレー)
└──────────────────────────┘  文字: 黒, サイズ: 16px
```

**ダンジャーボタン（削除など）**
```
┌──────────────────────────┐
│  リセット / 削除          │  背景: #FF3B30 (赤)
└──────────────────────────┘  文字: 白, サイズ: 16px
```

### カード / リスト項目

```
┌─────────────────────────────┐
│ アイコン  タイトル      サブ  │
│            サブテキスト       │
└─────────────────────────────┘
```

### ステータスインジケーター

- ✅ 成功 / 完了
- ⏳ 処理中
- ⚠️ 警告
- ❌ エラー / 失敗

### カラーパレット

| 用途 | 色コード | 説明 |
|------|---------|------|
| Primary | #007AFF | メインボタン（青） |
| Success | #34C759 | 成功（緑） |
| Warning | #FF9500 | 警告（オレンジ） |
| Error | #FF3B30 | エラー（赤） |
| Background | #FFFFFF | 背景（白） |
| Border | #E5E5EA | 境界線（グレー） |

## 画面遷移図

```
[スプラッシュ]
    ↓
[ウォレット作成] → [シードフレーズ表示] → [確認]
    ↓                                        ↓
[マイナンバー読取]
    ├─ Yes (18歳以上)  → [成功] → [メイン画面] ↗
    └─ No (18歳未満)   → [失敗]
                              ↓
[SaaS企業からリクエスト]
    ↓
[確認ダイアログ]
    ├─ キャンセル → [メイン画面]
    └─ 許可 → [トランザクション送信中] → [完了]
                                           ↓
                              [SaaS企業でサービス提供開始]
```

## フォント・タイポグラフィ

| 用途 | フォント | サイズ | 太さ | 行間 |
|------|---------|--------|------|------|
| タイトル | SF Pro Display | 32px | Bold | 1.2 |
| ヘッダー | SF Pro Display | 20px | Semibold | 1.3 |
| ボディ | SF Pro Text | 16px | Regular | 1.5 |
| キャプション | SF Pro Text | 12px | Regular | 1.4 |
| ボタン | SF Pro Text | 16px | Semibold | 1.2 |

---

## アクセシビリティ

- 最小フォントサイズ: 12px
- タッチターゲット最小サイズ: 44x44 dp (iOS) / 48x48 dp (Android)
- コントラスト比: WCAG AA 以上 (4.5:1)
- VoiceOver / TalkBack 対応
- ダークモード対応
